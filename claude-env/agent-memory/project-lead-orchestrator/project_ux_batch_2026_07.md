**Item 7 — the DayBoundary "logical day" seam (load-bearing, the highest-risk item):**
- `domain/DayBoundary.kt` = the SINGLE source of "which logical day is it." Pure fns take explicit `cutoffHour`/`zone` (testable); a process-wide `@Volatile var cutoffHour` holder is what the ~80 file-scope/UI derivations consult. `PreferencesManager.dayBoundaryHour` (KEY `day_boundary_cutoff_hour`, default 4, range 0..6) getter/setter + init-block keep the holder in sync. Formula: `logicalDate(ms) = atZone(ms).minusHours(cutoff).toLocalDate()`; `toLogicalMillis(ms)=ms-cutoff*3.6e6` (DST-safe, identical to minusHours for time-based unit). Setting control is in Settings→Training, INSTANT-APPLY, deliberately OUTSIDE the save/regenerate `hasChanges` flow (no regen needed — pure derivation).
- **Converted to logical-day:** WorkoutRepository file-scope helpers `thisMonday/currentDayOfWeek/mondayOf/dayOfWeekOf` (now cutoff-aware; `mondayEpochMillisOf` helper; Monday still returns actual Mon-00:00 millis so `planned_exercises.weekStart` keys stay addressable); `autoLogRestDays` (todayEpoch + epochDayOf); `GamificationRepository` streak; `StatsRecomputer.startOfDayEpoch`; `HomeViewModel.todayCompleted`; `HomeFragment.dayOfWeekFromMs`; `getTrainingDayEpochs` (DAO now returns raw `getCompletedSessionDateMsDesc`, repo maps via `logicalEpochDay`+distinct — was SQL UTC-day `dateMs/86400000`); and DISPLAY date labels via `toLogicalMillis` in HistoryLog/SessionAdapter/HistoryRecap(session+PR)/HistoryProgress/RecapTrends/HomeFragment-recent/HistoryViewModel(search+CSV)/AiRepository history-date.
- **DELIBERATELY LEFT ON MIDNIGHT (document before touching):** `DailyChallengeManager` weekly-challenge key (changing it shifts existing users' challenge resets — same rationale as the old locale note); `ChartAxis.dateLabels` tick labels (≤6h shift is invisible at multi-week scale AND shifting breaks ChartAxisTest / risks tick-label misalignment); the rolling date-RANGE filters (`HistoryViewModel.filteredSessions` WEEK/MONTH windows, strengthHistory month window) — those are durations, not day attributions.
