Complete visual redesign of the app to the **"Auros"** design system (spec: `Change docs/DESIGN.md` — abyssal dark-teal "observatory": deep teal canvas `#012624`, tonal surfaces trench `#011D1C` → reef `#003734`, luminous teal→cyan accents, geometric-sans display type, depth via tone not shadows). **SHIPPED v1.19.0 (2026-07-01, commit 184c253 on main, tag v1.19.0, GitHub release live + API-verified, signed release APK `treningsprogram-v1.19.0.apk` 103 MB, DB unchanged).** User drove it directly (redesign → "extend eyebrows" → "build+install" → "ship"); staged **only `app/`** to avoid sweeping the 70 unrelated working-tree entries (docs/flows/binaries/.gitignore). Signed via existing `keystore.properties`+`keystore.jks`; pushed + released using the token in `~/.git-credentials` (credential.helper=store). **Install to a device was NOT done** — no physical device on adb and Waydroid session STOPPED; per [[feedback_always_skip_waydroid]] I didn't auto-start it (user installs the APK themselves).

**User decisions that shaped it:** (1) keep gamification accents VIVID against the abyss (gold level-up, green done-states, amber deload/streak, violet cardio) rather than pure-Auros cool-only; (2) bundle **Inter** as the Matter substitute.

**How it was built (high-leverage, resource-first):**
- `res/values/colors.xml` — full Auros palette (`auros_abyss/trench/reef/fog/ice/snow/teal/cyan/lilac…` + `game_gold/amber/green/violet`) and the Material semantic aliases point at it.
- `res/values/themes.xml` — remaps every Material role → Auros; global `fontFamily=@font/inter`; shapes 6/12/16dp; component styles `Widget.Auros.Button/.Ghost/.Tonal/.Text`, `.Card`, `.TextInput`, `.BottomNav` (+ active-indicator); `TextAppearance.Auros.Eyebrow` + tight-tracking headline overrides. Because ~all 44 layouts use `?attr/` semantic tokens + `textAppearance*`, this one file re-skinned the whole app.
- `res/font/inter.ttf` = official Google Fonts **variable** Inter (has wght axis). Weights via `android:fontVariationSettings` on widget styles — **must be double-quoted in XML** (`"'wght' 600"`) or aapt fails ("invalid unicode escape").
- Drawables retinted (level badge/day-selected → teal→cyan gradient; eyebrow dot; `bg_gradient_accent`; check/day/spec/achievement/launcher-bg).
- Legacy hardcoded hex migrated by sed in **layouts** and **Kotlin** (`#7C67F5` purple→`#7FE9E1` cyan, old neutrals→fog/reef, old cyan `#00BCD4`→violet). Kept categorical/semantic data-viz palettes (muscle-group legends, PR types) vivid.
- Signature polish extended app-wide via a reusable `Widget.Auros.Eyebrow` TextView style (teal beacon dot as `drawableStart` + tracked-out uppercase via `textAllCaps`, so source label strings stay title-case). **Hero bands** (eyebrow + tight display title, + gradient rule on 3) on the tabs: Home, Program, Profile, History (History hero has no rule to save vertical space; its TabLayout also restyled — cyan indicator/ice-selected/fog-unselected). **Section-header eyebrows** now on ~18 screens / 45 labels: Home (5), Profile (3), History stats/progress/recap_trends, exercise_detail, settings root + about + ai/app/training/backup/debug/unrecognized (the settings screens already had an uppercase LabelSmall+colorPrimary triplet — unified to the eyebrow style via a Python pass that collapses the 3-line signature; **watch out: that pass can drop a trailing `/>` when the letterSpacing line also closed the element — happened once in fragment_settings_unrecognized, detect with a next-line check**), setup_wizard (STEP label + 4 profile sub-labels), dialog_update_prompt. Deliberately left as theme-only recolor (no eyebrows): log_workout (focused active-session screen), list/RecyclerView screens (exercise_library, gym_presets, weekly_summary, xp_log, history_log/recap, prompt/rejection/crash logs). Error-colored labels (CRASH LOG, DANGER ZONE) kept red for warning semantics.
